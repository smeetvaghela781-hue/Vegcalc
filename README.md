# VegCalc Pro — Vegetable Mandi Tracker (Mobile & Excel Web App)

A lightweight, Excel-grade vegetable vendor intake, cost-per-kg, retail pricing, and profit tracking application modeled on `Veg_Business_Tracker.xlsx`.

## 📱 How to Install on Android Mobile Phone

### Method 1: Instant 1-Click Install (PWA)
1. Make sure your phone is connected to the same Wi-Fi or hotspot as your PC.
2. On your phone's browser (Google Chrome, Brave, or Samsung Internet), open:
   ```
   http://192.168.43.63:5174/
   ```
   *(Or click the **"📲 Phone App"** button on the PC to scan the QR code directly with your phone camera!)*
3. Tap the **3 dots (⋮)** at the top right of Chrome.
4. Tap **"Install app"** or **"Add to Home screen"**.
5. An official app icon (**🥬 VegCalc**) will be installed on your Android home screen!
6. **100% Offline**: Once opened, the Service Worker caches all files—you can take your phone to the mandi without any internet or mobile data!

---

### Method 2: Convert to a Standalone APK file
If you want to create a standalone `.apk` file to send over WhatsApp or install directly:
1. Open [PWABuilder.com](https://www.pwabuilder.com/) in your browser.
2. Enter your app's deployed URL or use GitHub Pages.
3. Click **"Package for Android"** ➔ Download the generated `.apk` package!
